# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-06-12

### Added
- Initial release of Panel de Operaciones Mooving
- Interactive dashboard with KPIs (Total Hours, Daily Average, Active Users, Unique Clients)
- Multi-select filters for months and categories
- CSV file upload functionality with dynamic data loading
- Workload distribution by employee with breakdown by client
- Monthly distribution table by client
- Monthly availability table with free time calculation
- Bag of Hours section (Tareas Internas and Reuniones de Equipo)
- Dynamic charts: Monthly trends, Top 10 Users, Top 10 Clients
- Working days calculation for 2026 (Argentina) with holidays
- Responsive design for mobile and desktop

### Technical
- Monorepo structure with Vite + Vue 3 frontend
- Hono + Cloudflare Workers backend
- Cloudflare D1 database
- Semantic versioning
